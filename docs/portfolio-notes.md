# Portfolio notes

This project demonstrates practical AI-agent harness usage for marketing operations:

- Structured tool calls instead of unsupported guesses
- Independent retrieval of account, campaign, ad-set, ad, and creative data
- Deterministic currency and metric checks
- Explicit uncertainty handling
- Read-only account safety
- Human decision checkpoint before any campaign change
- Reusable PDF output for stakeholder review

The system is intentionally designed so the agent performs research, extraction, organization, and critique while the human retains final control over strategy and changes.
